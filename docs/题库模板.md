# 题库模板（供 AI 批量出题用）

> 用途：把本文件连同你的出题要求一起交给 AI，让它按下面的格式产出一批题目，
> 再通过「管理端 → 题库管理 → JSON 批量导入」粘进去。
>
> 导入是**按 `id` upsert**：带 `id` 且已存在则更新，否则新增。
> 想要"整批新增"，把 `id` 字段全部删掉即可。

---

## 1. 给 AI 的指令模板（复制这段改）

```
请按《题库模板.md》的 JSON 格式，为我生成 20 道题，要求：

- 主题范围：<例如：安全生产法律法规、消防常识>
- 题型配比：单选 12 道、多选 5 道、判断 3 道
- 难度：以一线员工的应知应会为主，不要偏题怪题
- 每题 4 个选项（判断题不用填选项）
- 分值：单选 5 分、多选 10 分、判断 2 分
- 解析：用一句话说明依据或知识点
- 输出：只要一个 JSON 数组，不要额外解释文字

严格遵循模板里的字段名、题型取值、选项 key 取值与"正确答案必须是选项 key"的约束。
```

---

## 2. 输出格式（JSON 数组）

```json
[
  {
    "type": "single",
    "stem": "我国的安全生产方针是（　）。",
    "options": [
      { "key": "A", "text": "安全第一、预防为主、综合治理" },
      { "key": "B", "text": "生产第一、安全第二" },
      { "key": "C", "text": "效益优先、安全兼顾" },
      { "key": "D", "text": "先生产、后安全" }
    ],
    "answer": ["A"],
    "score": 5,
    "tags": ["安全生产"],
    "analysis": "《安全生产法》确立了安全第一、预防为主、综合治理的方针。"
  },
  {
    "type": "multi",
    "stem": "以下属于特种作业的有（　）。",
    "options": [
      { "key": "A", "text": "电工作业" },
      { "key": "B", "text": "焊接与热切割作业" },
      { "key": "C", "text": "高处作业" },
      { "key": "D", "text": "办公室文秘工作" }
    ],
    "answer": ["A", "B", "C"],
    "score": 10,
    "tags": ["安全生产", "特种作业"],
    "analysis": "特种作业指容易发生事故、对操作者本人及他人安全健康有重大危害的作业。"
  },
  {
    "type": "judge",
    "stem": "从业人员有权拒绝违章指挥和强令冒险作业。",
    "options": [],
    "answer": ["对"],
    "score": 2,
    "tags": ["安全生产"],
    "analysis": "《安全生产法》赋予从业人员拒绝违章指挥的权利。"
  }
]
```

### 可选字段 `id`

```json
{ "id": 12, "type": "single", "stem": "…", "...": "…" }
```

- 带 `id`：更新该题（用于修订已有题目）。
- 不带 `id`：新增。
- **不确定时就不要写 `id`**，避免覆盖掉已有题目。

## 3. 字段约束（务必遵守，否则导入会报错）

| 字段 | 必填 | 约束 |
|---|---|---|
| `type` | ✅ | 只能是 `single`（单选）/ `multi`（多选）/ `judge`（判断） |
| `stem` | ✅ | 非空纯文本；不要用 Markdown 语法（系统按纯文本渲染） |
| `options` | ✅ | 数组，见下方规则；判断题可传 `[]` |
| `answer` | ✅ | 正确答案的 **选项 key** 数组，必须是 `options` 里出现过的 key |
| `score` | ✅ | 大于 0 的数字 |
| `tags` | 建议 | 字符串数组；**组卷抽题按标签进行，没有标签的题抽不到** |
| `analysis` | 建议 | 解析文本；仅管理端可见，不会下发给考生 |

### 选项（`options`）规则

- 每项形如 `{ "key": "A", "text": "选项内容" }`。
- `key` 用 `A`、`B`、`C`… 依次排列，**不要跳号、不要重复**。
- 至少 2 个选项（判断题除外）。
- 题干里如需留空，用全角括号 `（　）`，避免显示成 `()`。

### 正确答案（`answer`）规则

| 题型 | 规则 |
|---|---|
| 单选 | **恰好 1 项**，例如 `["B"]` |
| 多选 | **1 项或以上**，例如 `["A","C"]`；顺序不影响判分 |
| 判断 | **恰好 1 项**，且只能是 `"对"` 或 `"错"` |

### 判断题的选项

判断题不需要写 `options`（写 `[]` 即可），系统会自动使用固定的「对 / 错」两个选项，
且考生端**不会打乱**判断题的选项顺序。

---

## 4. 判分规则（影响你怎么出题）

| 题型 | 判分 |
|---|---|
| 单选 | 完全匹配得满分，否则 0 分 |
| 判断 | 完全匹配得满分，否则 0 分 |
| 多选 | 不选 0 分；**选了任何错误选项 0 分**；只选正确项但漏选按比例得分 |

多选漏选得分公式：`满分 × (选对数量 ÷ 正确选项总数)`，保留 1 位小数。

> 例：正确答案 `ABC`，满分 10 分
> - 选 `AB` → 10 × 2/3 = **6.7**
> - 选 `A` → 10 × 1/3 = **3.3**
> - 选 `ABCD` → **0**（含错误项）
> - 选 `AD` → **0**（含错误项）

**出题建议**：多选的正确项不要太多（3~4 个为宜），
否则漏选得分会很零碎，区分度下降。

---

## 5. 自检清单（交给 AI 后人工抽查）

- [ ] `type` 只有 `single` / `multi` / `judge` 三种取值
- [ ] 每道题的 `answer` 都能在 `options` 的 `key` 里找到
- [ ] 单选与判断题的 `answer` 恰好 1 项
- [ ] 判断题的 `answer` 只用了 `"对"` 或 `"错"`
- [ ] `score` 都是正数
- [ ] 多选题的正确项数量在 2~4 之间
- [ ] `tags` 用的是团队约定的标签体系（否则组卷时会抽不到题）
- [ ] 没有重复题干
- [ ] 输出是**一个 JSON 数组**，没有 Markdown 代码块以外的多余文字

> 导入前建议先用任意 JSON 校验器确认格式合法。
> 导入成功后题库列表会显示每道题的「上次被抽中」与「累计正确率」，可用于回查。

## 6. 空白模板（让 AI 逐条填）

把下面这段作为输出骨架：

```json
[
  {
    "type": "",
    "stem": "",
    "options": [
      { "key": "A", "text": "" },
      { "key": "B", "text": "" },
      { "key": "C", "text": "" },
      { "key": "D", "text": "" }
    ],
    "answer": [],
    "score": 0,
    "tags": [],
    "analysis": ""
  }
]
```

---

## 7. 导入方式

1. 管理端 → **题库管理** → **JSON 批量导入**
2. 粘贴 JSON 数组（支持 `[ ... ]` 或 `{ "questions": [ ... ] }` 两种形式）
3. 点「开始导入」，结果会提示「新增 X 题，更新 Y 题」

导入后可用 **导出 CSV** 核对内容是否符合预期。
