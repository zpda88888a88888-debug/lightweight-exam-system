# 管理员使用手册

> 适用对象：考试管理员（超级管理员，单账号）
> 打开地址：`http://<服务器地址>:8080/admin.html`
> 考生端地址：`http://<服务器地址>:8080/`

---

## 1. 登录

1. 打开管理端地址，输入**账号**和**密码**。
2. 账号密码由部署时在服务器环境变量中配置（`ADMIN_USERNAME` / `ADMIN_PASSWORD`），
   首次部署会随机生成一个密码并打印出来，请向部署人员索取。

> 忘记密码：需要部署人员在服务器上修改 `exam.env` 后重启服务，管理端无法自助重置。

---

## 2. 界面总览

左侧四个模块，**同一个功能只有一个入口**：

| 模块 | 干什么 |
|---|---|
| **考试管理** | 建考试、发布、归档、查看成绩与统计 |
| **考生管理** | 选一场考试，导入名单、生成邀请码、看谁没来/谁在考 |
| **试卷管理** | 只读查看每场考试抽中的题目（含正确答案） |
| **题库管理** | 题目增删改查、批量导入、导出、题目统计 |

一次考试的完整流程：

```
题库管理 建题  →  考试管理 建考试（选标签+题数）
                        ↓
              考生管理 导名单 → 生成邀请码 → 导出并分发
                        ↓
              考试管理 发布（此时抽题、冻结）
                        ↓
                  考试当天（考生管理 看状态）
                        ↓
              考试管理 → 成绩/统计 → 导出成绩 CSV
```

## 3. 题库管理

### 3.1 新增单题

点右上「+ 新增题目」：

| 字段 | 说明 |
|---|---|
| 题型 | 单选题 / 多选题 / 判断题 |
| 分值 | 数字，大于 0 |
| 题干 | 纯文本 |
| 选项与正确答案 | 填选项内容，勾选「正确」的那一项（可多项） |
| 标签 | 逗号分隔，**组卷抽题靠它**，务必规范填写 |
| 解析 | 仅管理端可见，不会下发给考生 |

- 默认给 4 个选项，**用不到的直接留空即可**，保存时会自动丢弃空选项。
- 判断题不需要填选项，系统固定用「对 / 错」。
- 「+ 添加选项」最多可加到 8 个。

### 3.2 批量导入（推荐）

点「JSON 批量导入」，粘贴 JSON 数组，点「开始导入」。

- **按 `id` upsert**：带 `id` 且已存在则更新，否则新增。
- 想整批新增，把 `id` 字段去掉。
- 导入结果会提示「新增 X 题，更新 Y 题」。

格式与出题要求详见 **`题库模板.md`** —— 那份文件可以直接连同你的出题要求一起
交给 AI，让它按格式产出一批题目。

### 3.3 导出题库

点「导出题库 CSV」，得到一份包含选项、答案、分值、标签、解析以及统计列的表格，
可用于备份或线下审校。列的含义见下节。

### 3.4 题目统计

列表里每道题都显示两个统计值：

| 列 | 含义 |
|---|---|
| **上次被抽中** | 最近一次抽中该题的**考试名称**与**抽题时间**；显示「暂无」表示从未被任何考试抽中 |
| **累计正确率** | 正确次数 ÷ 所有已判分提交次数，后面括号里是样本量，如 `75%（6/8）` |

> **「暂无」和「0%」是两回事**：
> 「暂无」= 这题还没考过，或考了但没人作答；
> `0%` = 确实有人做过，但全都做错了。
> 看到 0% 才说明这道题可能有问题。

### 3.5 编辑与删除的限制

- **已被已发布考试引用的题目不能改、不能删**，会提示"已被已发布考试引用"。
  这是为了保证已发布试卷不变（试卷是发布时的快照）。
- 未被引用的题目可以自由编辑、删除。
- 草稿考试尚未生成试卷，其涉及的题目仍可编辑。

## 4. 考试管理

### 4.1 查询考试

页面顶部可按以下条件查询（可组合）：

| 条件 | 匹配方式 |
|---|---|
| 状态 | 草稿 / 未开始 / 进行中 / 已结束 / 已归档 |
| 选聘编号 | 包含匹配（大小写不敏感） |
| 考试名称 | 模糊匹配 |
| 开考时间 | 起始日 ~ 截止日（按你电脑的本地时间） |

有任一条件生效时会出现「清除」按钮，一键恢复完整列表。

### 4.2 新建考试

点「+ 新建考试」，需要填写：

| 字段 | 说明 |
|---|---|
| 考试名称 | 显示给考生的名字 |
| 选聘编号 | **全局唯一**，字母数字，如 `ZP2026001` |
| 开考时间 | 本地时间。**早于该时间考生无法登录** |
| 截止时间 | 本地时间。到点自动交卷，且不能再开始 |
| 及格比例 | 10%~90%，9 档 |
| 组卷规则 | 标签 + 该标签抽多少题 |

**关于及格比例**（界面也有同样的说明）：

> 按得分排名取前 X% 为及格；**同分并列者全部通过**，因此实际及格人数可能多于 X%；
> 分母为**已交卷人数**，缺考不计入。

**关于组卷规则的标签**：标签只能从题库已有标签中**下拉选择**，并会显示
「可用 N 题」。

- 下拉里没有你想要的标签 → 说明题库里还没有题目打这个标签，
  请先到「题库管理」给题目打上标签。
- 抽题数超过该标签可用题数时，输入框旁会**当场提示**，保存也会被拦截，
  不会等到发布才发现。

### 4.3 列表操作说明

| 考试状态 | 可用操作 |
|---|---|
| **草稿** | 编辑、发布、名单与邀请码（跳转考生管理）、删除 |
| **已发布** | 成绩/统计、查看试卷、归档 |
| **已归档** | 成绩/统计、查看试卷 |

### 4.4 发布考试

点「发布」，确认后系统会：

1. 校验每个标签的题量是否足够（不够会**指名具体标签**并拒绝发布）；
2. 按规则**随机抽题**，并随机固定题目顺序；
3. 生成**试卷快照**；
4. **冻结**：名单、邀请码、组卷、时间全部不能再改。

> ⚠️ **发布后不能撤销，也不能修改**。要改只能删除重建（已发布不能删除，
> 只能先归档）。所以发布前请仔细核对时间、名单和组卷规则。

> 发布前请先在「考生管理」把**名单和邀请码准备好**。

### 4.5 归档

考试结束后可点「归档」，表示这场正式封存。归档后不能修改，
但成绩、统计、试卷仍可查看。

## 5. 考生管理

这是"按考试场次"管理名单与邀请码的地方。

### 5.1 选择考试场次

上方是查询条件（与「考试管理」一致）和**可点击的考试列表**：

1. 用条件筛选（场次多时尤其有用）；
2. 在结果表格里**点任意一行**选中该场次。

选中后选择器会收起，显示「已选：场次信息 + 更换场次」，需要换场次点「更换场次」。

### 5.2 导入考生名单

> 仅**草稿**状态可导入。

CSV 表头必须为：`手机号,姓名,身份证号`

```
手机号,姓名,身份证号
13800000001,张三,110101199001010011
13800000002,李四,110101199001010022
```

可以选文件，也可以直接把 CSV 内容粘贴到文本框，然后点「导入到本场考试」。

导入规则：

- **身份证号全局唯一**。已存在则**更新**该考生的姓名与手机号（不会报错、不会重复建人）。
  所以同一份名单重复导入是安全的，改了手机号重新导入也能更新。
- 同一人参加多场考试时，复用同一份考生档案。
- 手机号需为 11 位、以 1 开头。
- 空行会被忽略。

### 5.3 生成邀请码

点「生成邀请码」/「重新生成邀请码」：

- 为名单中**所有**考生生成全局唯一的 **6 位数字**码。
- **重新生成会覆盖全部邀请码，旧码立即失效**，已分发的需要重新发放（会二次确认）。
- 仅草稿状态可生成。

点「导出邀请码 CSV」得到分发用的表格（手机号、姓名、身份证号、邀请码）。

### 5.4 查看谁在考试、谁没来

「参与状态」区域把考生分成四类，**每个状态标签后面带人数**，点一下即可筛出具体是谁：

| 状态 | 含义 | 你该做什么 |
|---|---|---|
| **未登录** | 从未用邀请码登录过 | 该催了——可能是没收到邀请码，或还没来 |
| **答题中** | 已登录并进入答题，尚未交卷 | 正常，不用管 |
| **已交卷** | 截止前正常提交 | 正常 |
| **超时交卷** | 到截止时间后才提交 | 成绩有效，但可能在导出里需要留意 |

名单表格里同时显示每人的**邀请码、状态、得分、交卷时间**。

> 人数统计始终按**全部名单**算，不随你当前的筛选变化，
> 所以「未登录 3 人」这个数字是可信的。

### 5.5 发布后

场次发布后，本模块变为**只读**，会提示"已发布，名单与邀请码已冻结"。
但**参与状态查询仍然可用**——考试进行中正是最需要看状态的时候。

## 6. 试卷管理

用于核对"这场考试到底抽了哪些题"。

- 列表显示每场已发布考试的**题数、试卷总分、及格比例、状态**。
- 点「查看试卷」进入详情，可以看到每道题的：序号、题型、题干、选项、
  **正确答案**、本题分值和解析。
- 试卷是发布时的快照，**只读**，不提供任何改题入口。
- 草稿考试还没有试卷（页面会提示"尚未发布，暂无试卷"）。

> 试卷详情里的题目顺序就是试卷里的实际顺序；考生端的选项内容会按各自账号乱序，
> 所以考生看到的选项排列可能不同，但**判分只看原始选项标识**，不受影响。

## 7. 成绩与统计

在「考试管理」列表里点已发布考试的「成绩/统计」进入。

### 7.1 统计卡片

| 指标 | 口径 |
|---|---|
| 名单人数 | 该场导入的考生总数 |
| 有 attempt | 已交卷的人数（正常提交 + 超时提交） |
| 缺考 | 名单人数 − 有 attempt（从未交卷） |
| 平均分 | 分母为**有 attempt 的人**，缺考不计入 |
| 及格线 | 按得分排名取前 `及格比例%` 的那一名的分数 |
| 及格率 | 及格人数 ÷ 有 attempt 的人数 |

**及格线的并列规则**：同分并列者**全部通过**。
例如 5 人考试、及格比例 40%（取前 2 名），第 2 名分数为 75 且有两人并列 75，
则这 3 人都算及格。

### 7.2 图表

- **题目标错率**（柱状图）：每道题"得分 < 满分"的比例。未作答算错。
  **柱子明显偏高的题，说明该题偏难或题目/答案可能有问题**，值得复盘。
- **及格情况**（饼图）：及格与不及格人数。

### 7.3 成绩列表

显示每人的姓名、手机号、得分、是否及格、切屏次数、状态、交卷时间。

### 7.4 导出成绩 CSV

点「导出成绩 CSV」，包含以下 13 列（顺序固定）：

```
选聘编号、考试名称、手机号、姓名、身份证号、邀请码、开始时间、交卷时间、
得分、是否及格、切屏次数、切屏时间点、状态
```

- **缺考考生也会出现**，得分为空、状态为「缺考」。
- 状态取值：`正常提交` / `超时提交` / `缺考`。
- 切屏时间点为 JSON 数组，记录每次切屏的时刻。

拿到 CSV 后请**线下告知考生成绩**——系统不提供考生自助查分入口。

## 8. 必须记住的几条规则

| 规则 | 说明 |
|---|---|
| **发布即冻结** | 发布后名单、邀请码、组卷、时间都不能改；要改只能归档后重建 |
| **邀请码唯一** | 6 位数字、全局唯一；重新生成会让旧码全部失效 |
| **身份证号唯一** | 全局唯一；重复导入是"更新"而不是"报错" |
| **判分只在服务端** | 试卷接口不下发正确答案，考生端拿不到答案 |
| **及格线含并列** | 同分并列全部通过，实际及格人数可能多于所设比例 |
| **缺考不算分母** | 平均分、及格率、标错率的分母都只算已交卷的人 |
| **交卷后不可查分** | 考生交卷后无法再登录，成绩只能由管理员线下告知 |
| **答案不落库** | 考生答题过程与服务器零交互，交卷时一次性提交 |

**判分规则**（影响你出题时的分值设计）：

| 题型 | 规则 |
|---|---|
| 单选 / 判断 | 完全匹配得满分，否则 0 分 |
| 多选 | 不选 0 分；**选了任何错误选项 0 分**；只选正确项但漏选按比例得分（保留 1 位小数） |

## 9. 考试当天检查清单

**考前 1 天**

- [ ] 题库题目、答案、标签核对无误
- [ ] 考试时间（开考/截止）确认，注意是**服务器所在时区**的本地时间
- [ ] 名单导入完成，身份证号无重复
- [ ] 邀请码已生成并**实际分发到每个考生**
- [ ] 考试已**发布**（未发布考生无法登录）
- [ ] 已执行一次数据库备份
- [ ] 试跑一场测试考试，用测试账号完整走一遍登录→答题→交卷

**考试当天**

- [ ] 服务已启动（部署人员确认）
- [ ] 管理端 →「考生管理」→ 选本场 → 看**未登录人数**，及时催场
- [ ] 开考后观察**答题中**人数是否正常增长
- [ ] 临近截止时提醒考生尽快交卷

**考后**

- [ ] 确认所有人状态为「已交卷」或「超时交卷」
- [ ] 「考试管理 → 成绩/统计」核对及格率、题目标错率是否合理
- [ ] 导出成绩 CSV
- [ ] 执行一次数据库备份
- [ ] 线下告知考生成绩
- [ ] 考试可「归档」封存

## 10. 常见问题

**Q：考生说登录提示"手机号或邀请码错误"，怎么查？**
到「考生管理」选该场次，在名单里核对这个手机号对应的邀请码是不是你发给他的那个。
注意 6 位数字可能是 `012345` 这种带前导零的。

**Q：考生说"考试未开始"，但时间已经到了？**
检查考试的**开考时间**是不是设成了服务器时区以外的时间。
开考时间填的是你本机的本地时间，保存时会自动换算。

**Q：想改已发布考试的截止时间？**
不行。发布即冻结。只能归档后重新建一场。

**Q：名单导错了怎么办？**
只要考试还是**草稿**，重新导入正确的 CSV 即可（按身份证号更新，不会重复建人）。
已被引用的名单不想要，也可以直接删掉整场考试重建。

**Q：邀请码泄露给外人了？**
邀请码本身需要配合登记的手机号才能登录，风险有限。
如确实担心，在草稿状态下重新生成邀请码（旧码立即失效），并重新分发。

**Q：能不能让考生自己查成绩？**
不能，这是设计如此。系统不提供考生查分入口，成绩由你导出后线下告知。

**Q：为什么某道题的正确率是"暂无"？**
说明这道题从未被任何考试抽中，或者抽中了但从没有人作答过。
这不代表题有问题。

**Q：某题标错率特别高，是不是答案配错了？**
有可能。到「试卷管理」查看该题的正确答案，和题干核对一遍。
注意：如果考试已发布，**不能直接改题**，需要归档后重建这场考试。

**Q：导出 CSV 用 Excel 打开中文乱码？**
文件是 UTF-8 编码。用 Excel 请选择「数据 → 从文本/CSV 导入」并指定 UTF-8，
或直接用 WPS / 文本编辑器打开。

## 11. 需要联系部署人员的情况

以下操作管理端做不了，需要服务器上的运维操作：

| 情况 | 需要的操作 |
|---|---|
| 忘记管理员密码 | 修改 `exam.env` 中的 `ADMIN_PASSWORD` 后重启服务 |
| 服务无法访问 | 检查服务是否运行、端口是否被占用 |
| 需要备份/恢复数据库 | 使用部署包中的 `./manage.sh backup`（恢复见部署文档） |
| 修改端口或访问地址 | 修改 `exam.env` 中的 `PORT` 后重启服务 |
